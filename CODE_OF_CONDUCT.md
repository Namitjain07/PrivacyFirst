# Code of Conduct

## Our Commitment
We are committed to creating a respectful, secure, and harassment-free environment for everyone contributing to the PrivacyFirst project.

## Standards
### Positive behavior includes:
- Being respectful and considerate
- Giving and accepting constructive feedback
- Focusing on what is best for users’ security and privacy

### Unacceptable behavior includes:
- Harassment or discrimination of any type
- Trolling or insulting comments
- Publishing private information without permission

## Responsibilities
Project maintainers may remove or edit contributions that violate this Code of Conduct.

## Scope
This Code of Conduct applies within project spaces and in public spaces where an individual is representing the project.

## Enforcement
Instances of abusive behavior may be reported to the maintainer:  
**Email:** your-email@example.com

All complaints will be reviewed fairly.
